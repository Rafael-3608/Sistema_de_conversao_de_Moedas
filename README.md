# 💱 Conversor de Moedas em Java

Um conversor de moedas interativo em linha de comando desenvolvido em Java, utilizando estruturas de repetição, controle de fluxo e formatação de valores monetários.

## 🚀 Funcionalidades

- Menu interativo com validação de entradas do usuário.
- Conversão entre diferentes pares de moedas (Real, Dólar Americano e Euro).
- Tratamento de opções inválidas no menu sem encerrar o programa inesperadamente.
- Formatação de saída com precisão de duas casas decimais utilizando `DecimalFormat`.

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java
- **IDE:** VS Code / Cursor
- **Controle de Versão:** Git e GitHub
